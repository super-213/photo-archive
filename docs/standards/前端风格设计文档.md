# 个人摄影作品集网站｜前端风格设计文档

> 文档版本：v1.0  
> 更新日期：2026-11-10  
> 设计定位：**Photo-First Editorial Portfolio（照片优先的编辑式摄影作品集）**  
> 状态：设计基线，待真实照片验证与视觉定稿

## 1. 项目定位

网站用于展示并保存个人摄影作品，包括旅行、风光、城市街拍、人文、汽车以及模型/手办摄影。

**核心原则：照片是绝对主角，文字很少。** 网站既不是摄影博客，也不是公开图床，更不是社交平台；它应当像一座经过精心策展的私人线上摄影美术馆。

采用双层内容结构：

- **Works / Selected Works**：精选摄影系列，以项目为单位进行人工策展，突出摄影表达与作品质量。
- **Archive**：全部可公开展示的摄影档案，支持按题材筛选，便于浏览。

同一张照片可同时出现在摄影系列和 Archive 中，不重复存储。

### 1.1 设计目标

1. 进入网站时，用户首先注意到的是摄影作品，而不是 UI。
2. 不同题材的照片能够共存，形成统一且有辨识度的作品集。
3. 桌面端有杂志式编排，移动端依然具备高质量看图体验。
4. 精选作品强调视觉节奏，档案页强调快速定位和检索。
5. 设计既能体现审美，也方便摄影作品持续更新。

### 1.2 设计边界

- **采用**：当代编辑式设计（Contemporary Editorial）、画廊极简（Gallery Minimalism）、少量胶片档案式元信息。
- **不采用为主风格**：重度新粗野主义、复杂 3D、长篇旅行博客、花哨滚动特效、所有照片等尺寸强制裁切。
- 作品页文字为辅助信息；允许简短标题、地点、年份和必要的说明，但不要求每组作品写文章。

## 2. 视觉风格与设计语言

### 2.1 风格定义

**Editorial Travel Photography × Contemporary Minimalism × Gallery Minimalism**

以精致的摄影杂志为整体气质，以现代画廊的克制方式展示图片。视觉节奏来自照片尺寸、排列与留白，而非大量装饰元素。

**关键词**：留白、策展、版式层次、非对称、克制、沉浸、质感、精确。

### 2.2 配色 Token（建议初稿）

| Token | 色值 | 使用场景 |
|---|---|---|
| `--color-bg` | `#F7F6F2` | 主页面暖白背景 |
| `--color-surface` | `#FFFFFF` | 弹层与辅助区域 |
| `--color-text` | `#202020` | 主要文字 |
| `--color-text-muted` | `#777570` | 次要信息、照片编号 |
| `--color-border` | `#E4E1DA` | 分割线和细边框 |
| `--color-lightbox-bg` | `#101010` | 全屏看图背景 |
| `--color-lightbox-text` | `#F7F6F2` | 全屏看图文字 |

说明：色值属于初始设计基线。上线前需以真实照片验证整体色彩平衡和文本对比度。避免为网站指定抢眼的品牌强调色；照片本身构成主要色彩来源。

### 2.3 字体与层级

- **英文展示标题**：Instrument Serif；回退 `Georgia, serif`。
- **导航、正文、数字与元信息**：Inter；回退 `Arial, sans-serif`。
- **中文**：优先使用系统中文无衬线字体，如 `PingFang SC`, `Microsoft YaHei`, `sans-serif`；中文展示标题可在实际视觉测试后另选适配字族。
- **原则**：同一屏幕不超过两类明显不同的字体角色；避免大段展示性文字。

| 文字角色 | 桌面端参考尺寸 | 移动端参考尺寸 | 说明 |
|---|---:|---:|---|
| 首页主标题 | 48–80px | 32–48px | 根据照片调整视觉权重 |
| 页面标题 | 36–56px | 28–36px | 用于 Works / Archive |
| 项目标题 | 20–32px | 18–26px | 作品系列名称 |
| 导航与辅助标签 | 12–14px | 12–14px | 克制使用大写及字距 |
| 正文与简短说明 | 14–16px | 14–16px | 只在必要时出现 |

### 2.4 栅格、留白与页面宽度

- 容器最大宽度建议 **1440–1600px**，可按作品尺寸调整。
- 桌面端左右边距建议 `clamp(24px, 5vw, 96px)`。
- 移动端左右边距建议 16–24px。
- 主设计栅格为 12 列；图片布局可跨列，避免机械对齐。
- Works 页面采用大幅留白与非对称结构；Archive 页面采用高密度网格。
- 图片之间的空白是策展工具，但应避免为了“高级感”造成极端空洞。

### 2.5 摄影图片展示规范

1. **优先保留原始宽高比**，除明确用于封面构图的版本外，不强制将照片裁为相同尺寸。
2. 作品封面允许编辑选择焦点区域与裁切方式，但原照片始终可完整查看。
3. 重要大图应尽可能提供高质量响应式尺寸，不直接向所有设备下发原始全尺寸文件。
4. 图片按真实尺寸信息预留占位，避免页面滚动时跳动（CLS）。
5. 如需渐进式加载，可使用低清占位图或模糊预览；不使用抢眼的骨架屏干扰视觉。
6. 方向（横/竖）、宽高比、顺序和适合的布局模式作为作品编排依据。

## 3. 网站信息架构

```text
Home
├── Selected Works（精选摄影系列）
│   └── Project Detail（系列详情）
└── Archive（全部摄影档案）
    └── Photo Viewer（单图沉浸浏览）

Private Admin（仅本人访问）
├── Photos（上传、元信息、分类）
├── Projects（系列管理、照片排序、布局）
└── Site Settings（站点文案、封面、导航）
```

建议导航：`WORKS` / `ARCHIVE`；点击 Logo 回到 `HOME`。不要把每个题材都做成一级导航。

## 4. 核心页面设计

### 4.1 Home｜摄影集封面

**目标**：第一屏建立视觉气质，第二屏引导进入精选系列。

**建议结构**：

1. 极简顶部导航：站点名称 / Works / Archive。
2. 首屏 Hero：一张代表性横幅作品或经策展的主视觉；不在图片上叠加大段文字。
3. 极简标题：例如 `A Collection of Moments.`，附少量年份或摄影身份说明。
4. `Selected Work`：大、小、横、竖照片交错的精选系列封面，附系列名与年份。

**内容限制**：无轮播广告、无社交统计卡片、无长篇自我介绍、无复杂背景动画。

### 4.2 Works｜精选系列列表

**目标**：将摄影系列作为艺术作品组织，而非按题材罗列照片。

每个系列使用：封面图、系列名称、可选的年份 / 地点 / 类型。示例（仅命名示意）：

- `Beyond the Horizon` — 风光 / 旅行
- `Urban Silence` — 城市 / 街拍
- `Small Worlds` — 汽车模型 / 手办

**布局规则**：

- 以精选作品为单位，采用非对称编辑式网格。
- 核心项目可以大幅跨列，次要项目两列错位排列。
- 可为每个项目单独设置封面与排序。
- 用户在鼠标悬停时看到轻量标题变化，不遮挡主体；触屏设备直接显示项目名称。

### 4.3 Project Detail｜摄影系列详情

**目标**：通过照片顺序和版式构建观看节奏。

**布局组件建议**：

| 布局模式 | 用途 |
|---|---|
| `full-width` | 大型横图、全景、系列开场 |
| `single-centered` | 重点单幅作品、竖图 |
| `pair` | 两张有视觉关联的照片 |
| `asymmetric` | 一大一小或错位组合 |
| `triptych` | 三联作品（谨慎使用） |

每个系列由摄影者在后台自由安排照片顺序，并为照片选择合适的布局模式。初期建议每组约 10–25 张精选照片，仅作为编辑参考，不设技术上限。

**文字建议**：标题、地点/年份、可选一行简介。EXIF 在主动查看时出现；无需逐张配文。

### 4.4 Archive｜全部摄影档案

**目标**：快速浏览、筛选与定位作品。

**默认布局**：密度高于 Works 的规则网格；可使用等高行或自适应宽高比的网格，不必采用纯 Masonry 瀑布流。允许网格密度切换，例如舒展 / 紧凑。

**筛选选项**：全部、风光、街拍、旅行、人文、汽车、模型。

**筛选行为**：按题材筛选，在地址栏 URL 中反映状态，支持刷新、后退与分享。无结果时显示明确的空状态与查看全部照片入口。

### 4.5 Photo Viewer｜沉浸式浏览

- 深色背景 `#101010`，图片完整适配可视区域。
- 支持左右切换、键盘 `←` / `→`、`Esc` 关闭，以及移动端触控手势。
- 支持缩放查看细节，但应考虑移动端手势冲突。
- 默认隐藏大部分操作，只保留必要的关闭、导航和当前位置提示。
- EXIF 信息在主动展开后显示：机身、镜头、焦距、光圈、快门、ISO、日期等。
- 对私密位置数据提供隐藏策略，避免未经确认公开 GPS 精确坐标。

## 5. 交互与动效规范

### 5.1 基本原则

动画用来加强连续性和空间感，不应影响作品观看与页面性能。

| 场景 | 建议效果 | 参考时长 |
|---|---|---:|
| 图片初次进入视口 | 轻微淡入 | 250–350ms |
| 项目悬停 | 细微缩放或文字渐变 | 150–250ms |
| 页面切换 | 简洁淡入过渡 | 150–300ms |
| Lightbox 开合 | 平滑淡入 / 淡出 | 180–280ms |
| 筛选变化 | 网格平稳更新，避免错乱动画 | 150–250ms |

- 支持 `prefers-reduced-motion`，关闭非必要动画。
- 不强制滚动劫持，不采用影响无障碍的横向滚动作为唯一导航方式。
- 图片 Hover 效果不得作为获取信息的唯一方法。

### 5.2 可用性与无障碍

- 所有可点击元素有明确焦点态，并能使用键盘操作。
- 导航、过滤、图片查看器提供可理解的标签。
- 文字、按钮和辅助信息符合合理的对比度要求；对比度以实际实现验证。
- 支持响应式：手机、平板、常见桌面宽度以及超宽屏。
- 使用适当替代文本；纯装饰图片可设置空替代文本。

## 6. 响应式设计

| 区间 | 页面策略 |
|---|---|
| 手机：< 768px（参考） | 作品单列优先，Archive 2 列为常见情况；触控操作，简化导航 |
| 平板：768–1199px（参考） | Works 1–2 列混合，Archive 2–3 列 |
| 桌面：≥ 1200px（参考） | 12 列编辑式布局，Archive 3–5 列（按内容宽度调整） |

断点应由内容决定，而不是死板依赖设备型号。特殊横图在手机端保持完整构图，不允许关键主体被强制裁切。

## 7. 设计组件清单

- `SiteHeader` / `SiteFooter`
- `HeroPhoto`
- `ProjectCover`
- `EditorialProjectGrid`
- `ProjectPhotoLayout`（五种基础排版）
- `ArchiveFilterBar` / `ArchivePhotoGrid`
- `PhotoLightbox`
- `ExifPanel`
- `PhotoMetadata`
- `EmptyState` / `LoadingPlaceholder`

组件应统一使用设计 Token，避免在各页面重复写死颜色、字号和间距。

## 8. 视觉验收标准

- [ ] 首页第一屏以摄影作品为主体，导航和文字不争夺注意力。
- [ ] Works 的系列封面可以独立控制排序、焦点和布局，不是普通等尺寸卡片墙。
- [ ] Project Detail 支持全宽、居中、双图和非对称布局，完整尊重不同照片宽高比。
- [ ] Archive 支持题材筛选，操作清楚，移动端可用。
- [ ] Lightbox 显示完整照片，可键盘切换、Esc 关闭，并能按需查看 EXIF。
- [ ] 主要页面在深浅不同、横竖不同、题材不同的真实样片下保持协调。
- [ ] 移动端无横向溢出；图片加载过程中无明显布局跳动。
- [ ] 动画可以在减少动态效果偏好下停用；键盘焦点可见。
